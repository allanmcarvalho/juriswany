# Instale ou atualize o Juriswany pela conversa

O operador pode pedir:

```text
gpt instale a skill https://github.com/allanmcarvalho/juriswany
```

Ou:

```text
gpt atualize a skill https://github.com/allanmcarvalho/juriswany
```

Agente, siga o [procedimento de seleção, inspeção e instalação](skills/juriswany/references/instalacao.md). Na primeira instalação, use a última release estável publicada. `main@dev` é uma escolha explícita pelo desenvolvimento. Na atualização, preserve o canal e o destino existentes, salvo pedido de mudança.

O procedimento usa as ferramentas do host para preparar a revisão em uma pasta temporária. Inspecione o conteúdo antes de executar scripts do pacote. Depois publique a cópia com as proteções do instalador. Execute os detalhes técnicos para a pessoa, sem delegar a ela o uso de terminal.
