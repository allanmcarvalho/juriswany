# Identidade visual do Juriswany

Juriswany combina o universo jurídico e a jurisprudência com o nome Tawany.

## Logo

A [logo principal em PNG](juriswany-logo-clara.png) reúne uma personagem meiga, uma balança da Justiça e flores rosas. Os tons de rosa acompanham a homenagem à Tawany. A personagem é simbólica e não representa um retrato dela.

O arquivo tem fundo branco. A versão do README usa largura de 360 pixels para preservar a leitura do nome.

## Slogan

> Um toque de carinho em cada direito.

O slogan liga a proposta de apoio à rotina jurídica ao carinho que deu origem ao projeto. Ele fica como texto no README, separado da imagem.

## Criação

A logo foi criada com assistência de IA, usando a ferramenta integrada imagegen. O [prompt de criação](logo-prompt.txt) registra a direção visual e o texto pedido.
