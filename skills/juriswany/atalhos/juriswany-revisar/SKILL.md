# Juriswany: Revisar minutas

Este atalho equivale ao pedido `$juriswany revisar`. Antes de executar, leia as [instruções da skill principal](../../SKILL.md). Se o host apresentar este atalho por um link simbólico, resolva o caminho real deste arquivo para localizar essa referência.

Siga a rotina `revisar` da skill principal e o pedido da pessoa. As instruções compartilhadas regem o perfil, o modo de execução, as fontes e a revisão profissional. Localize o utilitário e as demais referências a partir da pasta real da skill principal.
